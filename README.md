# 📖 GenAI Story Generator

An AI-powered Story Generator developed using **Python** and **Generative AI** concepts with the **Hugging Face Transformers** platform. The application generates creative, meaningful, and context-aware stories based on user-provided topics such as **Python**, **Data Science**, **SAP**, **Data Analytics**, and many others.

---

# 🚀 Project Overview

The **GenAI Story Generator** is a Natural Language Processing (NLP) application that utilizes a pre-trained Transformer model to generate human-like stories from simple text prompts.

The project demonstrates how **Generative AI** can automate creative content generation while showcasing the capabilities of Large Language Models (LLMs).
